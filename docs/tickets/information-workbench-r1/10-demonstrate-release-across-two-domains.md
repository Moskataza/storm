# T10: Demonstrate R1 across finance and the Chinese AI market

## Parent

[Information Workbench R1 specification](https://github.com/Moskataza/storm/issues/1)

## What to build

Deliver reproducible operator demonstrations and release evidence for financial information work and Chinese AI-market research using the same worksheet-to-report product. Prove that source capability descriptions, usage estimates, actual observations, and exported artifacts match the capabilities advertised for R1.

## Acceptance criteria

- [ ] Provide runnable financial and AI-market fixture tasks through the same workflow; one uses Automatic mode and one demonstrates Guided review/redirection.
- [ ] The financial example distinguishes individual bonds, bond funds, and yield-series data, without assuming unconfigured real-time or comprehensive bond coverage.
- [ ] The AI example covers hardware, software, agent skills, workflows, prompt packs, agent systems, and platforms with overlapping/extensible categories; sample observations remain distinct from wider market claims.
- [ ] Each example produces inspectable worksheet/plan, evidence, processing results, usage summary, browser/HTML/PDF reports, and declared coverage limits.
- [ ] Include observed live demonstrations for configured search, an accessible web page, and a catalogue-derived API; include dated Rednote/Bilibili probe outcomes and keep unsupported capabilities visibly limited/unverified.
- [ ] Consolidate provider-rate assumptions and measured-run comparisons, plus installation/rendering/fidelity evidence. An unperformed check is explicitly unverified and cannot support a readiness claim.
- [ ] Run the deterministic application/browser suite and legacy compatibility scenario, then follow the documented local operator quickstart from a clean task workspace.
- [ ] State R1 exclusions, including hosted multi-user service, full audiovisual analysis, and original-summary-video generation, while showing the stored report content can support future output modules.

## Specification coverage

AC21, consolidated AC22, AC23, and end-to-end verification of AC01–AC24.

## Blocked by

- T05: Acquire web evidence with browser fallback and honest access gaps.
- T06: Use a custom source and Python processing module in a report.
- T08: Review and redirect a guided task without losing its history.
- T09: Deliver matching browser, HTML and PDF report artifacts.

## Demonstration

Follow the operator quickstart to complete both domains, inspect their reports, and review a release capability matrix with source-access, cost, and export evidence.
