# Use a demand worksheet as shared task context

Use an editable demand worksheet, refined through conversation, to express the user's purpose, questions, scope, value criteria, processing needs, and deliverable requirements. Collection, processing, analysis, and writing should be guided by this shared task context: a topic alone does not express what makes the resulting information useful or how it should be presented.

This supports information work across subject areas; financial research is an example rather than the product boundary. A structured worksheet adds clarification work compared with accepting only a free-form topic, but makes the user's intended outcome available throughout the task and gives the user an explicit place to correct it.
